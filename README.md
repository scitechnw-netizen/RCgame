# RC QUEST — เกมตามหา RC

เว็บแอปมือถือสำหรับการแข่งขัน 14 ทีม ใช้ **GitHub Pages** เป็นหน้าเว็บ และ **Supabase** เป็นฐานข้อมูล ตัวตรวจคำตอบ และตัวจับเวลาฝั่งเซิร์ฟเวอร์

## ระบบการแข่งขัน

1. นักเรียนเลือกทีม แล้วกด **เริ่มเกม**
2. Supabase สุ่มลำดับสถานีทั้ง 14 จุดให้แต่ละทีมแบบไม่ซ้ำ
3. ระบบแสดงคำถามเปิดสถานที่
4. ตอบถูกแล้วจึงแสดงคำใบ้ พร้อมข้อความสีแดงว่า **“ให้ไปอ่านโจทย์ที่สถานที่ในคำใบ้”**
5. ที่จุด RC เว็บแสดงเฉพาะช่องกรอกคำตอบ ไม่แสดงโจทย์ ณ สถานที่
6. ตอบผิดต้องตอบข้อเดิมใหม่ ตอบถูกจึงไปสถานีถัดไป
7. ครบ 14 จุด ระบบถามผลรวมสุดท้าย คำตอบคือ `397,765.6`
8. เมื่อจบเกม ระบบหยุดเวลา บันทึกผล และแจ้งให้กลับไปที่หอประชุมเจ้าปู่หอคำ

## ระบบ Admin และการจัดอันดับ

ข้อมูลการแข่งขันไม่แสดงในหน้าเกมของนักเรียนแล้ว ผู้จัดเกมเปิดหน้า:

```text
https://ชื่อผู้ใช้.github.io/ชื่อ-repository/admin.html
```

รหัส Admin เริ่มต้น:

```text
1212312121
```

หน้า Admin มี 3 เมนู:

- **ภาพรวม** — จำนวนทีมทั้งหมด ทีมที่ส่งแล้ว ทีมที่กำลังเล่น และทีมที่ยังไม่เริ่ม
- **รายงานทีม** — เวลาเริ่ม เวลาส่ง เวลาที่ใช้ จุดปัจจุบัน สถานะ และจำนวนครั้งที่ตอบผิดของทั้ง 14 ทีม
- **จัดอันดับ 7 กลุ่ม** — รวมเวลาทีมย่อยเป็นคู่และเรียงจากเวลารวมน้อยไปมาก

การจับคู่กลุ่มใหญ่เป็นแบบตายตัว:

| กลุ่มใหญ่ | ทีมย่อยที่นำเวลามารวม |
|---|---|
| 1 | ทีม 1 + ทีม 2 |
| 2 | ทีม 3 + ทีม 4 |
| 3 | ทีม 5 + ทีม 6 |
| 4 | ทีม 7 + ทีม 8 |
| 5 | ทีม 9 + ทีม 10 |
| 6 | ทีม 11 + ทีม 12 |
| 7 | ทีม 13 + ทีม 14 |

กลุ่มใหญ่จะได้รับอันดับเมื่อทีมย่อยทั้ง 2 ทีมส่งสำเร็จแล้วเท่านั้น นอกจากนี้ยังมีเครื่องมือเลือกทีม 2 ทีมเพื่อทดลองคำนวณเวลารวมได้เอง

## ไฟล์สำคัญ

- `index.html` — หน้าเกมนักเรียน
- `app.js` — การทำงานของเกม
- `styles.css` — รูปแบบหน้าเกม
- `admin.html` — หน้าเข้าสู่ระบบและ Dashboard ผู้จัดเกม
- `admin.js` — รายงานและการคำนวณอันดับแบบรวมคู่
- `admin.css` — รูปแบบหน้า Admin
- `results.html` — ส่งต่อ URL ตารางคะแนนเดิมไปยังหน้า Admin
- `config.js` — URL และ Publishable/anon key ของ Supabase
- `supabase/schema.sql` — ติดตั้งฐานข้อมูลทั้งหมดสำหรับโครงการใหม่
- `supabase/admin-upgrade.sql` — เพิ่มระบบ Admin ให้ฐานข้อมูลเดิมโดยไม่ลบผลการแข่งขัน

## อัปเกรดจากเวอร์ชันเดิม

กรณีเกมเดิมใช้งานได้อยู่แล้ว ให้ทำตามลำดับนี้:

1. เปิด Supabase Dashboard > **SQL Editor**
2. คัดลอกไฟล์ `supabase/admin-upgrade.sql` ทั้งหมดไปวาง แล้วกด **Run**
3. อัปโหลดไฟล์เว็บเวอร์ชันใหม่ทั้งหมดขึ้น GitHub repository เดิม
4. รอ GitHub Pages Deploy เสร็จ
5. เปิด `admin.html` แล้วเข้าสู่ระบบด้วยรหัส `1212312121`

ไฟล์อัปเกรดจะไม่ลบ `game_sessions` จึงไม่ทำให้ผลการแข่งขันเดิมหาย

## ติดตั้งโครงการใหม่

1. สร้าง Project ใหม่ใน Supabase
2. เปิด **SQL Editor**
3. คัดลอกไฟล์ `supabase/schema.sql` ทั้งหมดไปวาง แล้วกด **Run**
4. ไปที่ **Project Settings > API**
5. คัดลอก Project URL และ Publishable key หรือ anon key
6. เปิด `config.js` แล้วแทนค่า

```js
window.RC_CONFIG = {
  SUPABASE_URL: "https://xxxxxxxx.supabase.co",
  SUPABASE_ANON_KEY: "ใส่-key-ที่นี่"
};
```

ห้ามใส่ `service_role` key ในหน้าเว็บ เพราะเป็นกุญแจสิทธิ์สูง

## เปลี่ยนรหัส Admin

รันใน Supabase SQL Editor โดยแก้ `รหัสใหม่` เป็นรหัสที่ต้องการ:

```sql
update public.game_admin_settings
set password_hash = encode(digest('รหัสใหม่', 'sha256'), 'hex'),
    updated_at = clock_timestamp()
where setting_key = 'main';
```

## เปลี่ยนชื่อ 14 ทีม

```sql
update public.game_teams set name = 'ชื่อทีมใหม่' where id = 1;
update public.game_teams set name = 'ชื่อทีมใหม่' where id = 2;
```

แม้เปลี่ยนชื่อทีม ระบบจับคู่ยังอิงหมายเลขทีมเดิม 1–14

## นำขึ้น GitHub Pages

1. อัปโหลดไฟล์ทั้งหมด โดยให้ `index.html` อยู่ที่รากของ repository
2. เปิด **Settings > Pages**
3. ใน **Build and deployment** เลือก **Deploy from a branch**
4. เลือก branch `main` และโฟลเดอร์ `/(root)` แล้วกด Save

หน้าเกม:

```text
https://ชื่อผู้ใช้.github.io/ชื่อ-repository/
```

หน้า Admin:

```text
https://ชื่อผู้ใช้.github.io/ชื่อ-repository/admin.html
```

## ล้างผลเพื่อเริ่มการแข่งขันใหม่

```sql
truncate table public.game_sessions;
```

จากนั้นให้นักเรียนล้างข้อมูลเว็บไซต์ในเบราว์เซอร์ หรือเปิดลิงก์ใน Incognito ใหม่

## หมายเหตุด้านความปลอดภัย

- เฉลยอยู่ใน `game_stations` ซึ่งผู้ใช้ทั่วไปอ่านโดยตรงไม่ได้
- สถานะการแข่งขันอยู่ใน `game_sessions` ซึ่งไม่มี RLS policy สำหรับการอ่านโดยตรง
- รหัส Admin เก็บเป็น SHA-256 hash และตรวจผ่านฟังก์ชัน Supabase
- รหัส Admin เก็บใน `sessionStorage` ของแท็บ Admin และถูกลบเมื่อปิดแท็บหรือกดออกจากระบบ
- หน้าเกมนักเรียนไม่มีปุ่มดูอันดับหรือรายงานเวลา
