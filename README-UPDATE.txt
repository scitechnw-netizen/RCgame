RC QUEST — อัปเดตหน้า Admin และปุ่มเคลียร์ทีมที่เล่นจบแล้ว
=============================================================

สิ่งที่เพิ่ม
- มีลิงก์ “เข้าสู่ระบบสำหรับผู้จัดเกม” ที่หน้าเกม
- มีหน้า admin.html และหน้าล็อกอิน Admin
- เพิ่มเมนู “เคลียร์รอบเล่น”
- เลือกเคลียร์เฉพาะบางทีมที่จบแล้วได้
- เคลียร์ทีมที่จบแล้วทั้งหมดได้ในครั้งเดียว
- เมื่อเคลียร์ ทีมจะกลับไปอยู่สถานะ “ยังไม่เริ่ม” และนักเรียนชุดใหม่เลือกเล่นได้
- ทีมที่กำลังเล่นจะไม่ถูกลบด้วยคำสั่งนี้

วิธีอัปเดตฐานข้อมูล
1. เข้า Supabase > SQL Editor
2. เปิดไฟล์ supabase/admin-clear-upgrade.sql
3. คัดลอก “เนื้อหาภายในไฟล์ทั้งหมด” ไปวางใน SQL Editor
4. กด Run
5. เมื่อสำเร็จ ตาราง Results ด้านล่างควรแสดงชื่อ clear_completed_sessions

วิธีอัปเดต GitHub
1. เข้า Repository RCgame
2. อัปโหลดไฟล์ 4 ไฟล์นี้ทับของเดิมที่หน้าแรกของ Repository
   - index.html
   - admin.html
   - admin.js
   - admin.css
3. กด Commit changes
4. ห้ามลบหรือเขียนทับ config.js เดิม เพราะไฟล์ ZIP ชุดนี้ไม่ได้แนบ config.js มาให้
5. รอ GitHub Pages อัปเดตประมาณ 1–3 นาที
6. เปิดหน้าเกมแล้วกด Command+Shift+R (Mac) หรือ Ctrl+F5 (Windows)
