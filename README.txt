Student Profile V2.0 — อัปเดตเฉพาะหน้าเว็บ

1. แตก ZIP แล้วอัปโหลด index.html, style.css, app.js ทับไฟล์ชื่อเดียวกันใน GitHub Repository เดิม (ตำแหน่งเดิม)
2. เก็บ config.js เดิมไว้ ไม่ต้องแก้ และไม่ต้องรัน SQL ใหม่
3. รอ GitHub Pages deploy แล้วเปิดเว็บใหม่ (Ctrl+F5)
4. เข้า Admin ด้วยรหัสเดิม เลือกห้องเรียน กดแสดงรายงาน รูปนักเรียนจะแสดงในตาราง กดรูปเพื่อขยายและดาวน์โหลดได้

ใช้ฐานข้อมูลและ RPC เดิมทั้งหมด ไม่มีการลบหรือย้ายข้อมูลจากการติดตั้งอัปเดตนี้
โหมดเลขประจำตัวอย่างเดียวขึ้นอยู่กับ require_code ในฐานข้อมูลเดิม
ฟอนต์ Mitr จาก Google Fonts; หากโหลดไม่ได้จะใช้ฟอนต์สำรอง
CSV เป็นข้อมูลข้อความ ไม่รวมไฟล์ภาพ; ภาพปรากฏในรายงานบนเว็บและรายงานพิมพ์
ตรวจสอบ JavaScript และทดสอบใน Chromium ด้วยข้อมูลจำลองแล้ว ยังไม่ได้ทดสอบบน Supabase จริง
