Student Profile V2.1 — ปรับขนาดรูปและรายงานพิมพ์

1. แตก ZIP แล้วอัปโหลด index.html, style.css, app.js ทับไฟล์ชื่อเดียวกันใน GitHub Repository เดิม
2. เก็บ config.js เดิมไว้ ไม่ต้องรัน SQL ใหม่ ไม่ต้องนำเข้ารายชื่อใหม่
3. เมื่อ GitHub Pages deploy แล้ว เปิดเว็บใหม่ (Ctrl+F5)
4. เข้า Admin เลือกห้อง กดแสดงรายงาน รูปบนคอมพิวเตอร์ 128×152 px และมือถือ 96×116 px (แสดงครบภาพ ไม่ตัดขอบ)
5. กดพิมพ์รายงานหลังโหลดรูปเสร็จ เลือก A4 แนวตั้ง (Portrait) ขนาด 100% และปิด Headers and footers ของเบราว์เซอร์ หากจำเป็น
6. รายงานพิมพ์ 10 คนต่อหน้า 1 คนต่อแถวแนวนอน มีหัวรายงานและเลขหน้าทุกหน้า แสดงข้อมูลตามตัวกรองปัจจุบัน หากรูปโหลดไม่ได้จะมีข้อความกำกับ
7. หน้าอื่นและฐานข้อมูลใช้ระบบเดิมทั้งหมด

ทดสอบ JavaScript และการแสดงรายงานใน Chromium ด้วยรายชื่อสมมติ 23 คน ได้ 3 หน้า (10+10+3) และตรวจสอบตัวกรองและขนาดรูปบนมือถือแล้ว ยังไม่ได้ทดสอบเชื่อม Supabase จริง
